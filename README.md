# Velmora.Ai

Velmora.Ai is a static vanilla HTML, CSS, and JavaScript emotional support interface.

## GitHub Pages

This repository includes a root `index.html` that redirects to `mindful/`, so GitHub Pages can serve from the repository root.

## API Setup

Frontend-safe endpoint URLs live in:

`mindful/js/config/api.js`

Private API keys and Discord client secrets must live in a backend or serverless environment, not in GitHub Pages.

Read:

`mindful/DEPLOYMENT.md`
